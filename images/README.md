# 코스안내도 이미지

골프장이 제공하는 **실제 홀별 코스안내도**를 여기에 넣습니다. 스코어맵 페이지의 본체입니다.

## 파일명 규칙 (권장)

코스 데이터의 `course.image_prefix` 를 정해 두면 파일명만 맞추면 자동으로 잡힙니다.
JSON 을 홀마다 고칠 필요가 없습니다.

```
<prefix>_hole01.jpg          홀 안내도    -> 페이지 왼쪽 전체
<prefix>_hole01_green.jpg    그린 상세도  -> 오른쪽 '그린' 항목 위
<prefix>_hole02.jpg
...
```

예: `image_prefix: "ananti"` 면 `ananti_hole01.jpg`, `ananti_hole01_green.jpg`.
확장자는 `.jpg` `.jpeg` `.png` 를 찾습니다.

특정 홀만 다른 파일을 쓰려면 그 홀에 `"image"` / `"green_image"` 를 직접 적으면 규칙보다 우선합니다.

## 이미지 저장 방법

골프장 코스안내 페이지에서 홀 그림 위에 **오른쪽 클릭 → 이미지를 다른 이름으로 저장**.
브라우저 화면 전체를 캡처하면 주소창·북마크가 같이 들어가므로 이미지만 저장하세요.
가로가 긴 그림이 지면에 잘 맞습니다.

## 현재 상태

`ananti_hole01.jpg`, `ananti_hole01_green.jpg` 는 **자리 표시용 플레이스홀더**입니다.
아난티 남해 코스안내(<https://ananti.kr/ko/namhae/NH0201>)에서 1번홀 그림 두 장을 저장해
같은 이름으로 덮어쓰면 실제 안내도가 들어갑니다.
