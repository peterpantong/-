# 코스안내도 이미지

부곡CC 공식 홈페이지의 **홀별 코스안내도 18장**이 `course/` 에 들어가 있습니다.

| 파일 | 홀 |
|---|---|
| `course/w-01.png` ~ `course/w-09.png` | 서코스(OUT) 1~9번홀 |
| `course/e-01.png` ~ `course/e-09.png` | 동코스(IN) 10~18번홀 |

출처: <https://www.bkcc.co.kr/sub2_2> (코스안내 > 코스공략)

`data/bugok_cc.json` 의 각 홀 `"image"` 값이 위 경로를 가리키고 있습니다.

```jsonc
{ "hole": 1, "image": "images/course/w-01.png", ... }
```

이미지가 있는 홀은 페이지 왼쪽 단에 **실제 코스안내도(위) + 전략 개략도(아래)** 가 함께 들어가고,
없는 홀은 개략도만 크게 들어갑니다. 경로에 파일이 없으면 조용히 개략도만 그립니다.

## 다른 이미지로 교체하기

- 파일명은 자유이고, 해당 홀의 `"image"` 값과 맞추기만 하면 됩니다.
- 지원 형식: JPG, PNG
- 가로/세로 비율은 자동으로 맞춰 들어갑니다. 가로가 긴 이미지가 지면에 잘 맞습니다.
