# 코스안내도 이미지

골프장이 제공하는 **실제 홀별 코스안내도**를 여기에 넣습니다.

- 파일명은 자유이고, `data/bugok_cc.json` 의 해당 홀 `"image"` 값과 맞추면 됩니다.
- 권장 이름: `hole01.jpg` ~ `hole18.jpg`
- 지원 형식: JPG, PNG
- 가로/세로 비율은 자동으로 맞춰 들어갑니다. 가로가 긴 이미지가 지면에 잘 맞습니다.

```jsonc
{ "hole": 1, "image": "images/hole01.jpg", ... }
```

이미지가 있는 홀은 페이지 왼쪽 단에 **실제 코스안내도(위) + 전략 개략도(아래)** 가 함께 들어가고,
없는 홀은 개략도만 크게 들어갑니다. 경로에 파일이 없으면 조용히 개략도만 그립니다.

현재 `hole01.jpg` 는 **자리 표시용 플레이스홀더**입니다.
부곡CC 홈페이지 코스안내(<https://www.bkcc.co.kr/sub1_2>)에서 1번홀 안내도를 저장해
같은 이름으로 덮어쓰면 실제 안내도가 들어갑니다.
