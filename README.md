# 루트 최저가 주유소

출발지 · 경유지 · 도착지를 넣으면 **그 경로에서 실제로 들를 수 있는** 주유소를 값싼 순으로 보여줍니다.
경로는 [TMAP 자동차 경로안내](https://openapi.sk.com), 가격은 [오피넷](https://www.opinet.co.kr)(한국석유공사)에서 가져옵니다.
전국 어느 구간이든 됩니다.

## 왜 "경로에서 들를 수 있는" 이 중요한가

지도에서 가장 싼 주유소를 찍어주는 서비스는 많지만, 그게 **고속도로를 달리는 중에 옆으로 지나가는**
주유소라면 아무 쓸모가 없습니다. IC로 빠져나갔다 다시 들어와야 하니까요.

그래서 이 도구는 경로를 **일반도로 구간**과 **고속도로 구간**으로 잘라서 다룹니다.

| 구간 | 후보 주유소 |
|---|---|
| 일반도로 | 경로선에서 설정한 이탈거리 안에 있는 모든 주유소 |
| 고속도로 | **진행 방향 휴게소 주유소만** |

반대 방향 휴게소와, 경로가 지나지 않는 노선의 휴게소는 자동으로 빠집니다.
두 방향 휴게소는 본선을 사이에 두고 떨어져 있어서, 실제 주행 차선을 따라간 경로선과의
거리(기본 350m 이내)로 진행 방향 것만 남습니다.

고속도로 본선 옆이라 IC로 나가야 닿는 시내 주유소에는 **IC 밖** 표시가 붙고,
이탈거리는 일반도로 구간까지의 거리로 계산됩니다.

## 실행

```bash
cp .env.example .env      # TMAP_APP_KEY 를 채운다
npm start                 # http://localhost:3000
```

의존성이 없습니다. Node 20 이상이면 `npm install` 없이 바로 뜹니다.

### TMAP 앱 키

[SK 오픈API](https://openapi.sk.com) 에서 발급받아 `.env` 의 `TMAP_APP_KEY` 에 넣습니다.
키가 없어도 서버는 뜨지만, 장소 검색이 꺼지고 경로는 **정거장 사이를 직선으로 이은 근사값**이 됩니다
(좌표를 직접 입력해 쓸 수 있습니다). 실제 도로를 따라간 이탈거리와 고속도로 구간 판정은 키가 있어야 정확합니다.

## 폰에서 쓰기 — 인터넷에 올리기

내 컴퓨터를 켜두지 않아도 폰에서 링크로 열려면 서버를 인터넷에 올려야 합니다.
저장소에 `render.yaml` 이 들어 있어 [Render](https://render.com) 무료 플랜이면 클릭 몇 번으로 끝납니다.

1. [render.com](https://render.com) 가입 (GitHub 계정으로 로그인)
2. **New +** → **Blueprint** → 이 저장소 선택 → **Connect**
3. `render.yaml` 을 읽어 설정이 자동으로 잡힙니다. 환경변수 두 개만 채웁니다.

   | 이름 | 값 |
   |---|---|
   | `TMAP_APP_KEY` | 발급받은 TMAP 키 |
   | `ACCESS_CODE` | 원하는 접속 암호 (아래 참고) |

4. **Apply** → 1~2분 뒤 `https://<이름>.onrender.com` 주소가 나옵니다

이후 `main` 에 커밋하면 자동으로 다시 배포됩니다.

### 홈 화면에 앱처럼 넣기

주소를 폰 브라우저로 연 다음:

- **아이폰(Safari)** — 공유 버튼 → `홈 화면에 추가`
- **안드로이드(Chrome)** — 오른쪽 위 ⋮ → `홈 화면에 추가`

아이콘을 누르면 주소창 없이 앱처럼 열립니다.

### 접속 암호

주소를 아는 사람은 누구나 열 수 있고, 조회할 때마다 **내 TMAP 키의 하루 사용량**이 줄어듭니다.
`ACCESS_CODE` 를 정해 두면 그 암호를 아는 사람만 조회할 수 있습니다. 처음 열 때 한 번 물어보고
브라우저에 기억해 둡니다. 한글도 됩니다.

비워두면 암호 없이 누구나 쓸 수 있습니다.

### 무료 플랜에서 알아둘 점

15분 동안 아무도 안 쓰면 서버가 잠들고, 다음 접속 때 깨어나느라 **첫 화면이 50초쯤 걸립니다.**
그 뒤로는 정상 속도입니다. 유료 플랜으로 올리면 잠들지 않습니다.

## 쓰는 법

1. 출발지·도착지를 입력합니다. 장소 이름으로 검색해 고르거나, `35.1234, 128.5678` 처럼 좌표를 직접 넣어도 됩니다.
2. `＋ 경유지 추가` 로 경유지를 넣습니다 (TMAP 제한상 최대 5곳).
3. `경로 유가 조회` 를 누르면 경로가 지나는 시·군·구를 자동으로 찾아 그 지역 유가를 모두 가져옵니다.

### 지역을 바꿔가며 쓰기

특정 지역을 미리 박아두지 않습니다. 목록은 **쓰는 대로 채워집니다.**

- 조회에 성공한 루트는 **최근 조회**에 자동으로 남습니다 (최대 5개, 같은 루트는 중복되지 않고 맨 앞으로 올라옵니다).
- 마음에 드는 루트는 **저장**을 눌러 이름을 붙여 두면 **내 루트**로 따로 보관됩니다 (최대 30개).
- 다른 지역으로 갈아탈 때는 목록에서 **새 루트 — 입력 비우기**를 고르면 입력칸이 비워집니다.

| 버튼 | 하는 일 |
|---|---|
| **저장된 루트** | 내 루트와 최근 조회를 한 목록에서 골라 불러옵니다. |
| **⇅ 출발↔도착** | 출발지와 도착지를 맞바꿉니다. 경유지 순서도 함께 뒤집혀 그대로 돌아오는 길이 됩니다. |
| **저장** | 지금 입력한 루트에 이름을 붙여 내 루트로 보관합니다. |
| **삭제** | 고른 내 루트를 지웁니다. 최근 조회는 5개를 넘으면 오래된 것부터 밀려납니다. |
| **링크 복사** | 루트가 담긴 주소를 복사합니다. 그 링크를 열면 출발·경유·도착이 그대로 채워집니다. |

목록은 이 브라우저(localStorage)에만 남습니다. 다른 기기로 옮길 때는 링크 복사를 쓰세요.
링크에 담긴 좌표는 열 때 국내 범위와 정거장 개수를 다시 확인합니다. 어긋난 링크는 무시하고 빈 화면으로 시작합니다.

결과 화면에서 조절할 수 있는 것:

- **유종** — 휘발유 / 경유 / 고급휘발유
- **루트 이탈** — 경로선에서 몇 km 안쪽까지 볼지 (1~20km, 또는 제한 없음)
- **셀프 / 24시간 / 알뜰 / 상표 / 시·군** 필터, 이름·주소 검색
- **주유량(L)** — 각 주유소의 막대와 금액이 "이만큼 넣으면 루트 최저가보다 얼마 더 내는지"로 바뀝니다

왼쪽 레일은 구간별 최저가를 막대로 비교하며, 누르면 해당 구간으로 이동합니다.

## 구조

```
src/geo.js        좌표 변환(KATEC·UTMK → WGS84)과 거리 계산
src/opinet.js     오피넷 지역별 유가 조회 + 파싱 (20분 캐시)
src/tmap.js       TMAP 장소 검색 · 경로 · 역지오코딩
src/route.js      경로 GeoJSON → 일반도로/고속도로 구간 분해
src/stations.js   주유소를 구간에 붙이고 이탈거리·휴게소 여부 판정
src/plan.js       위 조각들을 엮는 조회 파이프라인
src/server.js     HTTP 서버 (정적 파일 + /api)
public/share.js   루트 저장·링크 직렬화 (브라우저와 테스트가 함께 씀)
public/           화면 · 홈 화면 추가용 매니페스트와 아이콘
render.yaml       Render 배포 설정
```

### API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/config` | TMAP 키 유무, 경유지 상한 |
| GET | `/api/poi?q=` | 장소 검색 |
| POST | `/api/plan` | `{start, goal, waypoints}` → 구간·주유소·집계 |

## 테스트

```bash
npm test
```

좌표 변환은 pyproj 로 뽑은 기준값과 1m 이내로 맞는지, 오피넷 파서는 실제로 받아온 응답 조각
(`test/fixtures/`) 으로 검증합니다. 서버 테스트는 TMAP·오피넷 호출을 가로채 전체 파이프라인을 돌립니다.

## 알아둘 점

- 가격은 주유소가 오피넷에 **직접 신고한 값**이고 하루에도 여러 번 바뀝니다. 화면의 기준 시각을 확인하세요.
- 이탈거리는 경로선까지의 **직선거리 근사치**입니다. 실제 진입·회차 거리는 더 길 수 있으니 지도로 확인하세요.
- 고속도로 구간 판정은 TMAP 이 주는 **도로 이름**(`…고속도로`)을 씁니다. 문서화되지 않은 코드값에 기대지 않습니다.
- 오피넷 공개 API 키 없이 웹 응답을 읽는 방식이라, 오피넷이 페이지 구조를 바꾸면 파서를 손봐야 합니다.
  그때는 명확한 오류 메시지를 냅니다.
