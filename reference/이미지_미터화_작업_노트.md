## 한 일

1. **원본 이미지 분리** — `images/ananti_holeNN.jpg`는 그린 확대도(왼쪽)와
   홀 전체 도면(오른쪽)이 한 장에 붙어 있었습니다. 채도(S)가 낮고 밝기(V)가
   높은 픽셀만 배경으로 보는 방식으로 좌우를 갈라, `ananti_holeNN.jpg`(홀
   도면)와 `ananti_holeNN_green.jpg`(그린 확대)로 나눴습니다. 원본은
   `images/_original_combined/`에 백업해 뒀습니다 — 좌표를 다시 잡아야 하면
   여기서부터 다시 자르면 됩니다(`tools/`에 스크립트는 못 남겼고, 필요하면
   이 세션 기록에서 `split_hole_images.py`를 다시 씁니다).
2. **야드 숫자 → 미터로 대체** — 사진 픽셀에 인쇄된 야드 숫자(체크포인트,
   그린 격자 눈금 등) 자리에, 같은 위치·같은 크기로 미터 값을 굵게 덮어
   썼습니다. 배경을 지우고 다시 그리는 인페인팅이 아니라 **원본 위에 크고
   굵게 겹쳐 가리는 방식**이라 정밀 좌표가 조금 어긋나면 옛 숫자가 살짝
   비칩니다(벙커처럼 좁은 자리는 겹쳐도 무방하다고 확인받음).
3. **외곽선 색 = 주변 배경색 파스텔** — 처음엔 흰색 고정 외곽선을 썼는데
   스티커처럼 떠 보인다는 피드백을 받고, 글자를 얹을 자리 주변 픽셀을
   실제로 샘플링해 그 색을 밝게(파스텔) 섞어 외곽선으로 썼습니다. 물가는
   옅은 파랑, 잔디는 옅은 연두로 자연스럽게 녹아듭니다.
4. **표지 사진** — 홈페이지 골프 코스 키비주얼(`golfclub-incourse-keyvisual-lg.jpg`)을
   받아 표지 배경으로 깔고 어두운 톤을 살짝 낮춰 흰 글씨가 읽히게 했습니다.
5. **레이아웃 버그 수정** (`yardagebook/book.py`, `diagram.py`)
   - 스코어 기록칸(4라운드 기록표)을 빼고 그 자리를 홀공략 도면으로 넘김
   - 실제 도면 이미지가 배정된 칸을 다 못 채우면(비율 문제) 남는 자리를
     자동으로 아래 이미지 쪽으로 넘겨 빈 여백이 안 생기게 함
   - 두 이미지(홀 도면 / 그린 확대)의 가로폭을 항상 맞춤 — 이미지 자체
     비율 때문에 폭을 다 채우면 세로가 넘칠 수 있어, 둘을 합쳐 칸을 넘길
     때만 폭을 비례로 줄임(그래도 서로 같은 폭 유지)
   - 이미지 테두리(`stroke=1` 사각형) 제거

## 좌표를 잡은 방법 — OCR 없이

이 환경에 이미지 인식 도구(예: nano-banana MCP)가 연결되지 않아서, 숫자
위치를 **눈으로 보고** 잡았습니다. 두 가지를 써봤고 정확도 차이가 컸습니다.

- **격자 오버레이 + 라벨 읽기**: 이미지 전체에 20px 격자를 긋고 라벨을
  찍어서 좌표를 읽는 방식. 격자가 촘촘해지면 라벨 숫자가 잘 안 읽혀서
  **여러 번 잘못 짚었습니다**(50~100px씩 벗어난 적 있음).
- **숫자 하나씩 개별로 크게 잘라 비율로 어림**: 숫자가 있을 법한 자리를
  넉넉하게 크롭해서 4배로 확대한 뒤, 그 작은 크롭 안에서 숫자가 몇 %
  위치에 있는지 눈대중으로 잡고 원래 좌표로 환산. **이쪽이 훨씬
  정확했습니다.** 다음에도 이 방식을 먼저 씁니다.

검산 없이 좌표만으로 진행했기 때문에, 18홀 전체가 픽셀 단위로 완벽하지는
않습니다. 특히 숫자가 밀집한 홀(6, 10, 15번)은 옛 야드 숫자가 옅게 남은
자리가 있습니다 — 값 자체는 전부 `yd × 0.9144`로 검산해 정확합니다.

## 데이터 병합 관련

이 작업 도중 다른 세션(`전인민 보기플레이`, Opus 5)이 같은
`data/ananti_namhae.json`을 독자적으로 채워 먼저 푸시했습니다(`c31d7ea`,
`b922317` — `marks`/`play`/`caution`/`tees_yd` 필드, 이 노트 폴더의
`제작_노트.md`가 그 결과물입니다). `git push`가 거부돼 병합했는데,

- 업스트림(그쪽) 데이터를 기준으로 삼았습니다 — 벙커 좌표(from/to)까지
  숫자로 검증해 넣었고, 이건 제가 못 한 부분입니다.
- 렌더러가 읽는 `keys`/`note` 필드는 업스트림에 없어서, `play`(티샷·세컨드·
  그린)와 `caution`·`title`에서 재구성해 얹었습니다.
- `keys` 텍스트에 남아있던 야드 표기는 미터로 환산했습니다 — 업스트림은
  "미터는 환산 말고 사이트 표기 그대로"라는 원칙(`제작_노트.md` 4번)을
  썼지만, 이 문서는 이미지까지 포함해 전체를 미터로 통일하는 게 목표라
  방향이 다릅니다. 다음에 이 둘을 다시 합칠 일이 있으면 이 차이를
  기억해 두세요.
